# 种子案例：某电子烟品牌在社交平台投放广告被罚 #种子库/待补

某电子烟品牌在短视频/社交平台投放产品广告，含"烟弹""替烟""潮流"等表述。
监管认定在互联网发布烟草（含电子烟）广告，违反《互联网广告管理办法》及广告法相关规定。
罚款20万元并下架。

要点：
- 禁止在互联网发布烟草广告（含电子烟）。
- "电子烟/烟弹/香烟"出现在互联网广告物料中即为高风险。
